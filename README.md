- **Repository:** https://github.com/05250173jnec-hue/portfolio

## Features

- Fully responsive layout for desktop, tablet and mobile
- Dark and light theme toggle (remembers your choice)
- Mobile navigation menu and highlighted menu link while scrolling
- Animated network background with moving data packets in the hero card
- Typing terminal animation showing networking and Linux commands
- Custom cursor that grows and shows labels (View, Open, Mail) over clickable items
- Certificate viewer: click a certificate to open it full size
- Animated counters in the Achievements section
- Back-to-top button
- Respects "reduce motion" settings and uses accessible labels and alt text

## Technologies

- HTML5
- CSS3 (grid, flexbox, custom properties, media queries)
- JavaScript (vanilla, no frameworks)
- Google Fonts: Dela Gothic One and Outfit

## Run locally

1. Download or clone this repository.
2. Keep all files and the `certs` folder together.
3. Open `index.html` in a web browser.

## Deploy with GitHub Pages

1. Upload all files and the `certs` folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute, your site will be available at `https://05250173jnec-hue.github.io/repository-name/`.
